# Izadora Souza · Storymaker

Landing page para captação de clientes da storymaker Izadora Souza, que atende a Região dos Lagos (RJ).

Site estático: `index.html`, `styles.css`, `script.js` e `assets/`. Não precisa de build.

## Ver localmente

```bash
python3 -m http.server 8080
# abra http://localhost:8080
```

## Antes de publicar

Em `script.js`, troque os placeholders em `CONFIG`:

- `whatsapp`: número com DDI e DDD, só dígitos (ex.: `5522988887777`)
- `instagram`: link do perfil
